# Hyster · El valor detrás de cada equipo

[Ver presentación](https://gonzalo954.github.io/hyster-valor-comercial/)

Presentación web para el equipo comercial de Hyster / Tattersall Maquinarias, preparada por GO Marketing.

## Uso

- Navegar con las flechas inferiores, las teclas izquierda/derecha o el índice.
- Activar **Guía del relator** para ver orientaciones de venta.
- Seleccionar una fuente de poder para explorar su aplicación.
- Editar horas y costo horario para dimensionar el impacto ilustrativo de una detención.
- Usar la opción de impresión al final para imprimir desde el navegador.

## Contenido

12 secciones: propuesta de valor; operación y respaldo; marca; dealer; servicio y repuestos; garantía; fuentes de poder; TCO; costo de detención; objeciones; diagnóstico; fuentes.

## Edición y publicación

`index.html` contiene estilos, código e imágenes incorporadas. No requiere instalación ni compilación. GitHub Pages publica desde `main`, directorio raíz. Las modificaciones de ese archivo actualizan la web.

## Fuentes y alcance

Las fuentes están enlazadas en la última sección. Imágenes y logos proceden del catálogo entregado por el cliente. No se concede una licencia de uso sobre marcas o fotografías de terceros.

El dato de más del 60% de marcas privadas no está acreditado en el informe aportado y no se utiliza como argumento. Validar por equipo las garantías, stock, disponibilidad tecnológica en Chile, cobertura y condiciones de servicio. El reconocimiento Dealer of Distinction corresponde a 2024, anunciado por Hyster en abril de 2025.
